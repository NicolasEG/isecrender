# ISEC Seguridad — sitio web

Sitio estático completo con tres páginas: Inicio, Servicios y Contacto.

## Uso

Abrí `index.html` en cualquier navegador. No requiere instalación ni compilación.

## Imágenes

El diseño usa fotografías modernas alojadas en Unsplash. Las piezas publicitarias originales de ISEC se utilizaron únicamente para extraer la información de contacto, servicios y protocolo; no forman parte visual del sitio.

Las fotografías pueden reemplazarse desde las URLs indicadas en `index.html`, `servicios.html` y `assets/css/styles.css`.
